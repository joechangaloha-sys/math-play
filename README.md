# Math Play — small puzzles, big ideas

Two browser-based experiments: **Shape Shifter** (matrix transformations) and **Route Finder** (combinatorics). Five levels each.

Play: https://joechangaloha-sys.github.io/math-play/

No account, backend, analytics, or live AI calls. Progress is stored locally in your browser. Google Fonts are optional and have system fallbacks.

## Run locally

Open `index.html`, or run `python3 -m http.server 8879` in this folder.

`engine.js` contains the puzzle rules; `app.js` contains the interface; `style.css` contains the presentation. No build step is required.
